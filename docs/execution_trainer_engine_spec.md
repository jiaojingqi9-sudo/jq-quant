## 二、最重要的一个发现

**光靠 TraderEx 的三类交易者，撑不出 NVDA 那样的盘口。**

NVDA 实测（8/4 盘中 361 张快照）：最优档中位 **230 股**、前 10 档 **6,499 股**、价差 **1 tick**。
这种「价差极窄 + 每档不厚 + 十档很深」的形态是**做市商挂梯子**挂出来的，
随机来的限价单堆不出这个样子——TraderEx 的合成盘口每档几十到几百股、价差 5 分，
那是一只低价低流动性股票的性格，跟 NVDA 完全不同。

**所以我们的代理要五类，不是三类**：TraderEx 的三类负责「行情怎么走」，
再加 ABIDES 的做市商负责「盘口长什么样」，最后加我们自己（练习者）。

## 三、五类代理

### 3.1 知情交易者（Informed）—— 采 ABIDES 的 ValueAgent

TraderEx 的做法是「知情者直接知道 P\*」。ABIDES 更真实：**它只看到带噪声的 P\***，
然后用贝叶斯滤波去猜。我们采后者。

- 观测：每次醒来，从真实基本面价格取一个带噪观测，噪声方差 `sigma_n`
- 更新：把新观测和自己的先验按各自精度加权合并（噪声越小越信观测；
  距上次观测越久越不信先验）
- 外推：不是拿当前估计比价，而是**按均值回复外推到收盘**得到 `r_T`，再跟中间价比
- 决策：`r_T` 低于中间价就卖，否则买
- 报价：以概率 `percent_aggr`（默认 10%）直接穿价差成交；否则被动挂，
  在价差内随机往里/往外挪，挪的幅度上限是 `depth_spread × 当前价差`
- 单量：初始化时在一个区间里随机（ABIDES 用 20–50 股，我们要按 NVDA 标定）
- 醒来间隔：指数分布，速率 `lambda_a`（ABIDES 默认 0.005）→ 即泊松到达

**保留 TraderEx 的那条强度规则**：当基本面跑到买卖价之外时，
知情者发市价单的比例从约 50% 提到约 70%。这是趋势启动的机制。

### 3.2 流动性交易者（Noise）

双边、随机、跟价格无关（模拟「自己要用钱」）。限价单和市价单都发。
提供噪音与基础深度。参数只有两个：到达率、单量分布。

### 3.3 技术交易者（Momentum）—— 采 ABIDES 的 MomentumAgent

- 信号：记录中间价序列，算 **20 期均线** 和 **50 期均线**
- 规则：20 期 ≥ 50 期 → 买，否则卖
- 下单：限价单，买单挂在卖一价、卖单挂在买一价（即「用限价单吃价」，
  比市价单温和，不会一路吃穿）
- 单量：初始化时在区间内随机
- 醒来：固定频率（ABIDES 默认 60 秒）

**同时保留 TraderEx 的那条规则**作为触发加强：连续 4 笔以上同方向成交或中间价同向跳动后，
提高下一张机器单是同向市价单的概率。两条规则不冲突——均线管中期方向，连击管瞬间加速。

### 3.4 做市商（Market Maker）—— 采 ABIDES 的 AdaptiveMarketMakerAgent

**这是让盘口像 NVDA 的关键。**

- 在中间价两侧各挂 `num_ticks`（ABIDES 默认 20）个价位的梯子
- 挂单窗口宽度：可固定，也可**自适应**——用观测到的价差的指数加权移动平均，
  参数 `spread_alpha`。市场一乱，它自动挂宽
- 每档挂多少：取最近一段时间**实际成交量的一个比例**（`pov`，默认 5%），
  并有一个下限 `min_order_size`
- 库存管理：`skew_beta` 非零时，按当前持仓用 sigmoid 函数把梯子往一边偏——
  手里多了就把买单挂薄、卖单挂厚
- 醒来频率：默认 **1 秒**，每次先撤掉全部旧单再重挂

### 3.5 练习者（你）

回合制。每一步可以：挂限价单（任意档位）、撤单、吃单（指定股数）、什么都不做。

## 四、基本面价格过程：两种要都有

| | TraderEx | ABIDES | 我们 |
|---|---|---|---|
| 形态 | **跳跃过程**：隔一段随机时间突然跳一下 | **均值回复**：向长期均值 `r_bar` 以速率 `kappa` 回归，叠加方差 `sigma_s` 的随机冲击 | **两个叠加** |
| 像什么 | 突发消息 | 日常波动 | 真实的一天两者都有 |

所以基本面 = 均值回复的连续过程 + 泊松到达的跳跃。
跳跃频率、跳跃幅度、`kappa`、`sigma_s` 全部从 NVDA 真实数据标定。
**教师端的 Increase / Decrease P\* 就是手动注入一次跳跃。**

## 五、撮合引擎

- **价格-时间优先**的连续订单簿。每个价位一个 FIFO 队列。
- 市价单逐档吃；限价单如果能立即成交就成交，否则进队。
- 撤单按订单 id。
- **练习者的单子和机器的单子走同一套撮合**——这正是合成市场比回放强的地方：
  你吃掉一档，做市商下一秒重挂时会看到成交量变了，会调整。市场真的对你有反应。
- 时间推进：离散事件。每个代理有自己的下次醒来时间，取最小的那个推进。
  回合制界面下，点一下就把事件队列跑到「当前时间 + N 秒」。

## 六、参数标定（写引擎之前必须先做）

从 108 天 NVDA 数据里估这些，**不照抄教材和 ABIDES 的默认值**：

| 参数 | 从哪估 |
|---|---|
| 价差分布 | LOB 快照的 `ask[0]-bid[0]` |
| 各档深度分布 | LOB 快照每档的量，按距最优价的档位分组 |
| 做市商 `pov`、`num_ticks`、`level_spacing` | 反推：调到合成盘口的深度剖面跟真实的对上 |
| 订单到达率 `lambda_a` | 用相邻快照的档位量变化推断挂撤单事件频率（OFI 用的就是这个量） |
| 单量分布 | 同上，用量变化的幅度分布 |
| 基本面 `kappa`、`sigma_s`、跳跃频率与幅度 | 中间价序列的均值回复回归 + 跳跃点检测 |
| 市价单占比 | 用成交量与档位消耗量的关系推（逐笔只有 17%，不能直接数） |

**验收标准**：合成市场跑一段，下面三个分布要跟真实 NVDA 同量级——
价差分布、前 10 档深度分布、5 分钟已实现波动率。对不上就调参数，不调就是玩具。

## 七、跟 TraderEx 的差异对照

| | TraderEx | 我们 |
|---|---|---|
| 知情者 | 直接知道 P\* | 带噪观测 + 贝叶斯滤波（更真实） |
| 做市商 | 无独立代理 | 有，自适应梯子（否则撑不出 NVDA 的盘口） |
| 基本面 | 纯跳跃 | 均值回复 + 跳跃 |
| 参数 | 教材默认值 | 从自己的 108 天真实数据标定 |
| 档位 | 5 分一档 | 1 分一档，远端可折叠 |
| 一局 | 一整个交易日 | 一个执行窗口（30–60 分钟） |
| 推进 | 实时 | 回合制 |
| 评分 | 四项加权 | 同上，另加到达价滑点、参与率、被动成交占比 |

## 八、待办与风险

1. **标定是前置任务**，没标定就写引擎等于瞎填数。先做这个。
2. **代理数量与性能**：ABIDES 能跑上万个代理是因为它为批量实验设计。
   我们是交互式练习，代理数量控制在几十到几百，够撑出像样的盘口即可。
3. **做市商是最难调的一个**。它决定盘口形态，参数错了整个市场就不像 NVDA。
   建议单独做一个「只有做市商 + 噪音交易者」的最小配置先调厚薄和价差，再加别的代理。
4. **（未核对）** 开源项目的许可证条款。我们读思路自己写，但要引用代码前得确认。
5. **待定**：任务量。建议 10 万股（≈ 前 10 档深度的 15 倍、占 10:00–10:30 市场成交 1.2%）。
