现在中英文 README 都有 macOS / Windows(cmd) / PowerShell 三套完整命令，版本上下限写清，死链清零（有脚本扫过）。

### 1.4 账本（最重要的一段，结论要记住）

**现象**：账本推算现金比券商少 **10,196.67**，而 6 只持仓逐只分文不差、成交按 order_id 差集一笔没漏。

**根因**：全部是**手续费估高了**，分红利息一分没有（模拟盘不派息不计息）。

用券商现金倒推真实费用：`起点现金 1,014,307.31 − 当前现金 551,724.80 − 成交净流出 447,127.39 = 15,455.12`，而账本记了 `25,651.79`。5624 笔、1,502,582 股，真实费率约 **0.0103/股**。

拿不同费率重算这 5624 笔去凑靶子：

| 配置 | 重算合计 | 每股 |
|---|---|---|
| 当前参数（佣金+平台+结算+TAF，都带最低收费） | 22,927.10 | 0.01526 |
| 去掉结算费 | 18,419.35 | 0.01226 |
| 去掉结算费 + 平台费不设最低 | 16,711.13 | 0.01112 |
| **去掉结算费 + 佣金/平台费都不设最低** | **15,000.62** | **0.00998** |

离靶子只差 454.50（2.9%）。**结论：富途美股模拟盘实收约佣金 0.0049/股 + 平台费 0.005/股，不设每笔最低收费、不收结算费**（结算费是港股的项目）。当前配置多算的就是这两块。

另外账本里存的 25,651.79 用当前参数重算只有 22,927.10 → 费率参数中途改过，**真要修得整体重算，改配置不够**。

**账户所有者 2026-08-06 决定暂不修**（差额占总资产 0.98%，优先级低）。参数和数据都写在 `src/taa_futu/stock_reconciliation_log.py` 的模块 docstring 里，哪天要修照着改。

**硬约束（实测）**：富途模拟盘禁用了这些接口——
```
order_fee_query          → 暂时不支持模拟交易
get_acc_cash_flow        → 模拟账户不支持查询现金流水
deal_list_query          → 模拟交易不支持成交数据
history_deal_list_query  → 模拟交易不支持成交数据
history_order_list_query → 可用，但返回字段里没有任何费用项
```
所以模拟盘拿不到费用真值，只能估或反推。真实盘接上就有。

**新增：每日对账快照** `src/taa_futu/stock_reconciliation_log.py`
- 每个清算日记一行：券商总资产/现金、账本推算现金、当日差额、与前一日的增量
- 目的是把「一共差多少」变成「哪天开始差的」——现在这 10,196.67 摊在 4 个月 5624 笔里，定位不到
- 清算日按**美东**计；同一天重复跑覆盖不追加
- 记录点挂在**股票页**（`account`/`projection`/`reconciliation` 那里本来就都在手），不另起常驻任务。代价是没开 app 的那天会缺
- CLI：`taa-futu stock-recon-snapshot` / `stock-recon-history`
- 首行已记：`2026-08-06  cash_gap 10,196.67`

## 3. 踩过的坑（别重复踩）

1. **改全局 `os.name` 会把 pathlib 一起带偏** — `Path()` 按 `os.name` 选 WindowsPath/PosixPath，monkeypatch 之后 pytest 自己的 cacheprovider 会炸。要测平台分支就用参数注入（`venv_command(..., on_windows=True)`）
2. **改 stack 权重默认值会挂 3 个测试** — `test_config` 一个、回测数值两个。试过改成 25/25/25/25，已回退
3. **让演示模式读 `.env.example` 会把页面搞断** — 那份配置连带打开需要联网抓行情的选项，股票页渲染到一半就停（实测页面从 3458 字掉到 1160 字）。已回退，改在 README 里写说明
4. **`device_bash` 跑 git 会留 `.git/index.lock`** — 沙箱对挂载目录没有 unlink 权限，删不掉。后果是 `sync_monorepo` 报 `fatal: working tree has modifications. Cannot add.`（看着像工作区脏，其实是 index 被锁）。**跑完 git 就跑一次邮差 `gitclean`**
5. **`device_stage_files` 可能返回过期快照** — 遇到过 report 里 bytes 对得上、实际内容是旧版。改完 Mac 上的文件后如果要在容器里验证，比 md5 确认
6. **沙箱不能删文件** — `rm` 报 `Operation not permitted`。只能 `mv` 到 `_to_delete/`，再让人删
7. **全套测试 27 分钟** — 股票页 e2e 要真渲染整个界面。改代码后别急着推，先 `tradetests_bg`

## 4. 怎么干活（工具速查）

**邮差**：常驻 macOS 进程，唯一有网络和 git 凭证的地方。往 `~/All here/futu_queue/` 写一个 `xxx.task.json`：

```json
{"skill": "taacli"}
```

几秒后同目录出现 `xxx.result.json`。常用：

| skill | 用途 |
|---|---|
| `taacli` | 跑 `taa-futu` 子命令（先写 `_taacli.txt`，一行一条） |
| `tradetest_one` | 跑单个测试（先写 `_test_target.txt`） |
| `tradetests_bg` | 后台跑全套，结果写 `trade/runtime/pytest_result.json` |
| `gitcommit` | 提交（先写 `commit_message.txt` 和 `commit_repo.txt`） |
| `sync_monorepo` | subtree pull + 推 GitHub |
| `gitclean` | 清三个仓库的 `.lock`，**跑完 git 就跑它** |
| `logclean` / `logclean_apply` | 新闻系统日志与历史轮转 |
| `accounts` / `positions` / `snapshot` | 富途只读查询 |

**改 `watcher.py` 会自动重启**（它比对自己的 mtime，变了就 `sys.exit(0)` 让 launchd 拉起）。加新 skill 就是往 `SKILL_REG` 里加一行 + 放脚本文件。

**云端容器**（`Bash` 工具）有网络、有 Playwright（`/opt/pw-browsers/chromium`）、Python 3.11。验证演示模式的标准做法：clone GitHub → `python3 -m venv .venv` → `pip install -e .` → 起 streamlit + Playwright 抓页面文字扫报错。缺 tkinter，`test_control_panel.py` / `test_unified_panel.py` 在容器里跑不了。
