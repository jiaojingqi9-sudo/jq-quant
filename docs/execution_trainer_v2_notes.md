# v2 实现记录 —— 队列竞争、真实成交量、日内曲线

接在 `execution_trainer_v1_notes.md` 后面。这一版的目标是**往券商真实下单场景靠**，
做了两件事：把市场的成交量对到真实值，把「排队排不上」这件事做出来。

---

## 一、v1 有一个数错了 11 倍

v1 用盘口快照（`lob.jsonl`）标定了一切。盘口快照能量准的是**盘口长什么样**——
价差、各档厚度，那是横截面性质，抽样几千次就够。量不准的是**一共成交了多少**，
那是累计量，漏掉的部分就是漏掉了，而这份数据的时间覆盖率只有两成多。

这次改用 1 分钟 K 线（`klines.jsonl`，交易所报的成交量，实测 390 根一根不缺）：

| | v1（盘口推的） | v2（K 线量的） |
|---|---|---|
| NVDA 盘中成交量 | 约 620 万股/天 | **7080 万股/天** |
| 每秒成交 | 267 股 | **3027 股** |

差 11 倍。后果是 v1 里 10 万股 = 10% 参与率，真实世界里同样 10 万股只有 0.9%——
**难度定错了一个数量级**。参与率是做大单唯一真正的约束，这个数错了，练什么都不对。

顺带发现 v1 那条「日内活跃度曲线」也是错的。v1 拿盘口的挂撤单事件数当替身，
算出收盘前半小时只有 0.77 倍；美股实际上收盘前是全天第二忙。那个替身量到的
是波动率和采集器的勤快程度，不是成交量。改用 K 线之后是标准的 U 形。

## 二、日内成交量曲线（5 个交易日的中位数）

| 时段(ET) | 相对全天 | 占全天 | | 时段(ET) | 相对全天 | 占全天 |
|---|---|---|---|---|---|---|
| 9:30 | **2.22x** | 17.1% | | 13:00 | 0.60x | 4.6% |
| 10:00 | 1.35x | 10.4% | | 13:30 | **0.51x** | 3.9% |
| 10:30 | 1.08x | 8.3% | | 14:00 | 0.62x | 4.8% |
| 11:00 | 0.94x | 7.2% | | 14:30 | 0.72x | 5.6% |
| 11:30 | 0.75x | 5.7% | | 15:00 | 1.13x | 8.7% |
| 12:00 | 0.67x | 5.2% | | 15:30 | **1.77x** | 13.6% |
| 12:30 | 0.64x | 4.9% | | | | |

最忙和最淡差 4.4 倍。开盘和收盘前这两个小时占全天成交的三成。
引擎里三股订单流都按这条曲线缩放，界面上实时显示当前时段的倍数。

**为什么必须有这条**：「在量大的时候多做」是做大单最核心的一课。
一整天流量都一样的话，这一课既练不到也测不出来。

### 数据体检挡掉了两天

- **2026-07-31**：K 线里混进了秒位不为 :00 的记录，收盘价范围 99.84→201.81。
  NVDA 那天没跌到 99，是别的标的的数据被打上了 NVDA 的 code。
  不挡的话这天会算出 2.6 亿股、VWAP 129.72。挡掉那些记录之后这天可用
  （385/390 分钟，6337 万股，VWAP 198.30）。
- **2026-08-03**：只有 199/390 分钟，采集器中午就断了。整天作废。

`calibrate_volume.py` 现在有三道体检：K 线根数要够 95%、日内涨跌不能超过 30%、
合并时再按根数挡一道。宁可少几天，不要脏数据进中位数。

## 三、盘口只有 3400 股，一天却成交 7080 万股——差额只能是藏起来的

这两个数都是实测，摆在一起就逼出一个结论：**盘口上显示的量只是冰山一角。**
单边前 20 档加起来 6000 股，而每秒要成交 3027 股——如果显示的量就是全部，
整个簿两秒钟就被吃穿了。

所以订单簿加了 `display` 字段：`qty` 是真实剩余量，`display` 是盘口上露出来的。
撮合和排队按 `qty` 全额算，`depth()` / `level_qty()` 只报 `display`。

- 做市商每档真实挂 6 倍于显示量（`mm_hidden_mult`）
- 新增一类「机构被动单」：每张 800 股，**完全不显示**，在最优价上排队

实测效果：**买一显示 132 股，实际压着 780–800 股。**
练习者挂在买一，界面会告诉他「排我前面 654 股」——盘口上看不见的那些。

这正好一箭双雕：既解决了 v1「全挂在买一稳赢」的毛病，又是显示深度和成交量
两组数据唯一自洽的解释。

## 四、订单流拆成两股

v1 只有一个 `agent_events_per_sec`，一个旋钮同时管「成交量」和「盘口厚度」，
调到深度对了成交量就差 11 倍。v2 拆开，各自对着各自的实测目标标定：

- `taker_events_per_sec = 30`：主动成交的流，对着 K 线的真实成交量标定
- `maker_events_per_sec = 3.5`：非做市商的挂单流，对着盘口各档厚度标定
- `inst_events_per_sec = 2.0`：机构被动单

## 五、验收（跑 30 分钟 × 6 个随机种子）

| 指标 | 目标（实测） | 合成市场 |
|---|---|---|
| 价差 1 tick | 40% | 39–42% |
| 价差 2 tick | 45% | 41–47% |
| 价差 3 tick | 13% | 11–16% |
| 前 20 档深度逐档误差 | —— | 平均 2.3–3.1% |
| 5 分钟已实现波动率 | 0.279% | 0.284–0.340% |
| **每秒成交量** | **3027 股 × 时段倍数** | **3119–3194（目标 3269）** |

比 v1 多了成交量这一条，而且时段倍数实测对得上：开盘 2.17x、午盘 0.62x、
收盘前 1.71x（目标 2.22 / 0.64 / 1.77）。

另外两个标定值现在从档案里读、不再是猜的：
- `depth_dispersion` 由 p25/p75 反解，实测 **0.684**（v1 里拍的是 0.35）
- `taker_events_per_sec` 由真实成交量 ÷ 平均单量倒推

## 六、修掉的一个隐蔽 bug：做市商挂梯子的顺序

做市商重挂时原本是「先挂梯子，再撤别人留在报价里面的旧单」。顺序反了：
梯子挂下去的第一张单会直接跟那些旧单成交掉、根本没挂进簿里，最优档就空了一格。
实测有 **14%** 的时候买一比做市商自己以为的低一个 tick，价差分布因此被撑宽一整档
（1 tick 只剩 27%，应该是 40%）。改成先撤后挂，立刻回到 39–42%。

## 七、难度曲线（每种打法 6 个随机日，对影子 VWAP）

| 打法 | 50 万股(5%) | 100 万股(9%) | 200 万股(16%) |
|---|---|---|---|
| 每回合等额打市价 | 5.8bp | 9.7bp | 17.4bp |
| 等额挂单不追 | 5.5bp | 7.1bp | 8.0bp |
| 只露小块 + 补市价 | 5.9bp | 9.8bp | 17.4bp |
| 挂单为主 + 落后补市价 | 2.0bp | 2.2bp | 1.9bp |

括号里是参与率。分数线维持 v1 的 **≤1 优秀、≤3 良好、≤7 及格**：
100 万股这一档，前三种打法基本不及格，只有耐心挂单的那种能过。
**任务量默认改成 100 万股**——10 万股在真实成交量下只有 0.9% 参与率，是热身。

### 冰山单确实有用

同样的打法、同样每回合挂 25,000 股，只改盘口上露多少：

| 露出量 | 对影子 VWAP |
|---|---|
| 全部露出 25,000 | 2.4bp |
| 露 2,000 | 2.4bp |
| **只露 200（冰山）** | **0.9bp** |

差 1.5bp。原因是抢价机制只看**露出来的量**——藏起来的部分别人看不见，
自然不会因此抢在你前面挂。露 2,000 和露 25,000 一样差，因为都超过了
「最优档平常厚度的两倍」这个阈值，抢价是触发/不触发的开关。

界面上下单区加了「盘口只显示（冰山）」输入框，露太多会当场警告。

## 八、还没解决的（v3）

1. **纯挂单的打法仍然偏容易**：99% 被动成交率在 16% 参与率下依然拿到 1.9bp。
   现实里做不到。原因是 NVDA 流量太大（每秒 3000 股），排在 800 股后面
   不到一秒就轮到你了——队列位置在这种流动性下本来就不太起作用。
   真正拦住现实中交易员的是「价格会跑掉」和「挂这么多量本身就推动市场」，
   前者已经建模，后者（抢价）目前只值 1.5bp，偏轻。
   v3 应该让抢价随露出量连续加码，而不是过阈值就固定 3 个 tick。

2. **第 20 档以外仍是外推**：标定只量到第 20 档。

3. **回合制的粒度**：一回合 60 秒里没法调整，真实 EMS 是连续的。

4. **还不是券商终端**：现在只有限价单、市价单、冰山单。真实下单终端还有
   算法单（TWAP/VWAP/POV/IS，选好参数交给算法跑）、母单子单视图、
   活动委托列表、实时 TCA 面板。这是往「像券商」再走一步的主要方向。
