# 策略文章选型

## 结论

本项目复现的是 Meb Faber 的 **A Quantitative Approach to Tactical Asset Allocation**，而不是去 GitHub 找一个“回测收益最高”的仓库。

## 为什么不是直接找 GitHub

- GitHub 上大量量化仓库没有原始研究依据。
- 许多项目有明显未来函数、幸存者偏差、过度参数拟合。
- 很多所谓高收益策略需要做空、杠杆、期货或高频执行，不适合富途模拟盘稳定复现。

## 为什么选这篇

这篇文章满足四个关键条件：

1. 有公开的一手文章和清晰规则。
2. 只需要月频收盘数据，复现成本低。
3. 可以 long-only，能映射成 ETF 组合。
4. 可以落地到富途美股模拟盘，而不依赖期货或复杂融资能力。

## 复现假设

原文讨论的是资产类别层面的趋势跟踪。为了把它接到富途模拟盘，本项目做了以下工程化映射：

- 美股：`US.SPY`
- 海外发达市场：`US.EFA`
- 中期美债：`US.IEF`
- REITs：`US.VNQ`
- 商品：`US.DBC`

策略规则保持不变：

- 用月末价格和 10 个月简单移动均线比较。
- 满足条件的资产等权持有。
- 不满足条件的资金留在现金。

## 工程化偏差

和论文原始回测相比，这个实盘版本有几个现实差异：

- 用 ETF 代理资产类别，不直接交易底层指数或期货。
- 资金空置按现金处理，没有显式计入短债收益。
- 下单使用富途快照和限价单，不是论文里的理想月末收盘成交。

这些偏差会让结果和论文不完全一致，但这是从研究走向可执行交易系统时合理且必要的折衷。
